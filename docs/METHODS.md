# 最终方法与实现边界

## 场景、输入与输出

用户在当前画面点击唯一可见行人框，系统创建独立目标会话。每帧输出 `session_target_id`、`tracker_id`、状态、有效性、边界框、时间戳和原因。线上算法接收当前及历史图像派生信息，不读取 GT ID、未来帧或事件清单。GT 只用于离线选择协议及评分。

状态包括 `UNSELECTED → TRACKING → LOST / VERIFYING → TRACKING`；超过搜索期限进入 `NEED_RESELECT`。选择失败不破坏原会话；重选与清除选择显式创建/清空策略状态。

## 固定流水线

YOLO26s O2M/NMS，输入 960，最低推理/检测保留分 0.001，NMS IoU 0.7，person 类。BoT-SORT 原生 `sparseOptFlow`，Lost 保留 `ceil(5×fps)` 帧，内置 ReID 关闭。ShortLink 与 A2 各自持有 `yolo26n-reid.onnx` 编码器，均为 448_RGB；BGR 图像仅在张量预处理转换一次 RGB。

| 参数 | 预训练参考配置 | 微调正式配置 |
| --- | ---: | ---: |
| ShortLink 余弦阈值 / 双向差距 | 0.50 / 0.03 | 0.50 / 0.03 |
| ShortLink 确认 / 年轻轨迹年龄上限 | 1 帧 / 0.5 秒 | 1 帧 / 0.5 秒 |
| A2 恢复相似度 / 竞争差距 | 0.60 / 0.05 | 0.70 / 0.05 |
| 恢复持续确认 | 0.15 秒且至少 3 次观察 | 0.10 秒且至少 3 次观察 |
| 搜索期限 | 6 秒 | 6 秒 |
| EMA 更新相似度 / 权重 | 0.90 / 0.10 | 0.85 / 0.05 |
| 模板容量 | 5 | 5 |

完整参数以 `configs/pretrained/{tracker.yaml,target.json}` 和 `configs/finetuned/{tracker.yaml,target.json}` 为准。GUI 和批处理默认使用微调正式配置；对照实验必须显式使用对应权重与参数。配置重命名没有修改参数值。

## A2 的独立实现

`target/a2/policy.py` 包含完整配置与策略；`geometry.py` 提供相机补偿后的几何计算；`memory.py` 提供可信模板库。A2 配置和策略均直接继承 `object`，不继承或导入旧 v1–v7 文件。部分内部方法按职责保留明确的回退顺序，避免整理代码改变实际分支行为。

1. 当前绑定 ID 先做外观核验；低质量框、连续外观不一致和不可见轨迹分别处理。
2. 运动历史经当前相机变换更新；GMC 失效清空旧坐标链，重新建立可信运动历史，避免拿旧画面坐标约束新画面。
3. 新 ID 恢复必须通过原始外观门槛；运动惩罚只调整排序和竞争差距，不增加外观证据。
4. 恢复需满足观察次数与有效持续时间；短暂运动异常可以暂停确认，暂停时间不算有效证据。
5. 同 ID 连续性、GMC 重建、小框证据有各自窗口与门控，不能无限刷新外观可靠时间。
6. 固定锚点保留初始身份，EMA 仅在高相似度、较高检测分且低重叠情况下更新。
7. 多模板库仅从可信同 ID 观察采样，保留容量与新颖性约束；模板评分只用于恢复候选分支，避免污染普通跟踪核验。

## ShortLink 与身份交接

ShortLink 在 BoT-SORT 的基础关联后，将符合外观、双向竞争和动态几何条件的年轻轨迹接回 Lost 身份。事件只在当前帧发布，记录年轻 ID、存活 ID、当前框和帧号；运行适配器还检查 Tracker generation。

A2 消费事件前核验存活轨迹、框、外观和运动一致性。通过后搬移绑定 ID 和待确认候选的身份，保留已经积累的确认时间与次数。重命名不能直接触发恢复成功，也不能绕过原确认条件。Calibrated448 残余匹配不在正式流水线中。

## PC 应用

Tkinter 管理窗口和点击；推理线程持有模型、Tracker 和 A2。图像坐标映射考虑缩放及留白，拒绝过期帧点击。支持暂停、逐帧、清除目标、重选、标注视频和 JSONL/MOT 结果导出。

持久缓存保存与选人无关的检测、轨迹、GMC 和同帧身份事件；每次重选使用新的 A2 状态。外观描述符按帧和框缓存，模板库、EMA 和确认状态不共享。原帧率回放是播放功能，不能视为实时推理 FPS。

当前没有机器人控制接口或板端部署结果；ONNX Runtime 在此用于外观编码。项目主张为视觉算法与 PC 应用的完成度。
