# 算法设计

## 工作流程

点击选人 → 行人检测 → 多目标跟踪 → 短轨迹重连接 → 指定目标身份恢复 → 视频显示与结果导出。

系统输出目标编号、轨迹编号、状态、图像坐标系下的边界框和时间戳。状态包括未选人、跟踪、丢失、确认和重新选人。恢复判断使用当前与历史观察；GT 用于初始化评价会话和评分。

## 检测与跟踪

- YOLO26s：O2M/NMS，输入 960，person 类，推理阈值 0.001，NMS IoU 0.7。
- BoT-SORT：`sparseOptFlow` 相机运动补偿，丢失轨迹保留 5 秒，内置 ReID 关闭。
- 外观编码：`yolo26n-reid.onnx`，448 RGB；短轨迹重连接与目标恢复各自调用编码器。

## 指定目标恢复

1. 跟踪期间核验绑定轨迹的外观；丢失或身份不一致时进入搜索。
2. 以外观相似度筛选候选，结合相机补偿后的运动位置和候选差距排序。
3. 候选通过连续观察确认后恢复绑定；短暂运动异常暂停确认。
4. 保留初始外观，使用 EMA 和可信模板库适应姿态变化。更新同时检查相似度、检测分数和目标重叠。

实现见 [身份恢复策略](../src/a1_tracker/target/a2/policy.py)、[运动约束](../src/a1_tracker/target/a2/geometry.py)和[模板库](../src/a1_tracker/target/a2/memory.py)。

## 短轨迹重连接与身份同步

短轨迹重连接将符合外观、双向竞争和几何条件的新轨迹接回此前丢失的编号。目标恢复模块接收当前帧的编号变更，核验存活轨迹的外观与运动后同步绑定，继续累计已有确认时间。帧号和跟踪器代际标识用于检查事件有效性。

## 参数

| 参数 | 预训练配置 | 微调配置 |
| --- | ---: | ---: |
| 重连接相似度／双向差距 | 0.50／0.03 | 0.50／0.03 |
| 重连接确认／新轨迹年龄上限 | 1 帧／0.5 秒 | 1 帧／0.5 秒 |
| 身份恢复相似度／候选差距 | 0.60／0.05 | 0.70／0.05 |
| 恢复确认时间／最少观察次数 | 0.15 秒／3 次 | 0.10 秒／3 次 |
| 搜索期限 | 6 秒 | 6 秒 |
| EMA 更新相似度／权重 | 0.90／0.10 | 0.85／0.05 |
| 模板容量 | 5 | 5 |

完整配置见 [预训练参数](../configs/pretrained/)与[微调参数](../configs/finetuned/)。默认使用微调配置。

## 视频交互

支持点击选人、暂停、逐帧查看、清除目标、重选和视频／JSONL／MOT 导出。检测、轨迹和外观特征支持缓存，每次重选重新建立目标状态。界面播放帧率与推理耗时分别记录。
